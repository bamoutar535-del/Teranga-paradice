## 🇫🇷 Description courte
Site vitrine bilingue (FR/EN) pour Shady’s Grill à Dakar, avec menu, galerie, carte Google Maps et design moderne. Déployé sur GitHub Pages pour les JOJ 2026.

## 🇬🇧 Short Description
Bilingual showcase website (FR/EN) for Shady’s Grill in Dakar, featuring menu, gallery, Google Maps integration, and modern design. Deployed on GitHub Pages for Dakar Youth Olympic Games 2026.

---

## ✨ Fonctionnalités
- Page unique responsive (`index.html`)
- Navigation claire (À propos, Menu, Galerie, Localisation, Contact)
- Galerie d’images (`assets/images/`)
- Carte Google Maps intégrée
- Widget Google Translate (FR ↔ EN)
- Design moderne avec CSS (`assets/css/style.css`)
- Footer avec informations de contact
